# Bastard Tactical

Live shop site for **Bastard Tactical** — home-based Type 07 FFL and gunsmith in Culloden, Georgia. Appointment only.

**Live:** https://rivers241140-alt.github.io/bastard-tactical/

## What this site is

Static single-page shop site: services (prepaid local FFL transfer $25 plus tax, gunsmith packages, custom builds, 3D print on demand, ammo), how appointments work, about, and contact.

## Files

- `index.html` — shop page
- `css/styles.css` — layout and type (system font fallbacks; no binary fonts in this repo)
- `js/main.js` — mobile menu
- `img/mark.svg` / `img/favicon.svg` — line torii mark
- `.github/workflows/pages.yml` — deploys GitHub Pages from the repo root on push to `main`
- `.nojekyll` — skip Jekyll processing on Pages
